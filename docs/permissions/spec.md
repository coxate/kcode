# KCode 权限系统 Spec

## 背景

ch05 完成系统提示工程化后，KCode 已能自主多轮思考、调用工具并根据结果继续执行，但工具执行尚未形成统一安全边界。ch06 引入分层权限系统：每次工具调用在执行前依次经过危险命令防护、Plan 任务约束、路径沙箱、分层规则、模式兜底和人在回路；拒绝作为结构化工具结果回灌给模型，而不是终止 Agent Loop。

## 目标

- 建立固定顺序、逐层短路的权限流水线，对外裁决统一为 Allow、Deny、Ask。
- 用不可配置的命令黑名单和不可绕过的项目路径沙箱建立硬边界。
- 支持用户、项目、本地三级规则、精确/glob 匹配及四档运行时模式。
- 提供允许本次、永久允许、拒绝本次三态审批，并安全持久化精确规则。
- 保留 Plan 严格只读调查、只读并发、取消安全及 ch05 缓存/reminder 行为。

## 功能需求

- **F1 调用预检与黑名单：** 未知工具和非法参数在权限前结构化拒绝。合法 Bash 在 shell 创建前匹配固定危险模式，命中后不可由规则或模式放开。
- **F2 路径沙箱：** Read、Write、Edit、Glob、Grep 的真实目标必须位于解析后的项目根内；不存在目标按既有祖先解析。Bash 不做路径沙箱。
- **F3 规则：** 使用 Bash/Read/Write/Edit/Glob/Grep 友好名，支持无模式、精确、`*`，文件路径额外支持跨目录 `**`。
- **F4 配置：** 独立加载 `~/.kcode/permissions.yaml`、项目 `.kcode/permissions.yaml`、项目 `.kcode/permissions.local.yaml`；本地 > 项目 > 用户，同层 deny > allow。单层损坏降级为空并警告。
- **F5 模式：** default 为读 Allow、写/Bash Ask；acceptEdits 为读写 Allow、Bash Ask；bypassPermissions 全 Allow，但不绕过硬边界。plan 仅允许文件读取和严格白名单 Bash。
- **F6 流水线：** 参数预检 → 黑名单 → Plan 约束 → 沙箱 → 规则 → 模式 → 人在回路 → 执行。终值立即短路，未命中继续。
- **F7 切换：** Shift+Tab 循环四档并跨轮保持；Shift 离开 plan 不批准计划，`/do` 回 default 并让下一任务消费一次计划；`/clear` 恢复启动模式。
- **F8 人在回路：** 三项菜单支持方向键、回车、1/2/3。永久允许原子写 local 精确规则，成功后才执行；失败返回 `permission_persist_failed`。
- **F9 Bash 一致性：** 所有获准 Bash 使用相同 shell 语义，保留超时、取消、输出限制和脱敏。
- **F10 回灌与保序：** 所有拒绝按调用 ID 和原顺序回灌；同批调用独立裁决，拒绝不终止 Loop。

## 非功能需求

- 黑名单、Plan 约束和沙箱不可绕过；路径归属不得使用字符串前缀判断。
- 权限配置错误只能降低能力；永久写入必须原子化且不覆盖损坏文件。
- 多轮、流式、并发调度、取消、历史、缓存和 reminder 不退化。
- Ask/副作用串行，无需审批的只读调用保持有界并发。
- 权限实现与 Provider 无关，六工具名称和 schema 不变。
- 警告、预览、错误和 TUI 不泄漏密钥或敏感内容。
- Python 3.11、pytest、Ruff 全部通过；测试不执行真实危险命令或网络请求。

## 不做的事

- 不限制网络、CPU、内存、进程数或速率，不建立审计日志。
- 不支持配置黑名单、多项目根、额外目录授权、MCP/插件权限或图形化规则编辑器。
- 不解析 Bash 中任意文件访问，不自动泛化规则或创建写文件父目录。
- 不热加载手工权限文件，不修改 Provider、Skill、记忆或缓存协议。

## 验收标准

- 危险命令及常见变体在 allow/bypass 下仍 Deny，且执行 spy 证明 shell 未创建。
- 所有文件工具阻止项目外、`..`、相似前缀和软链接逃逸；缺失内部目标不误判。
- 六友好名、精确/`*`/`**`、三级优先级和同层 deny 优先均可观测。
- 三层配置缺失/损坏安全降级，默认模式按本地、项目、用户生效。
- 模式矩阵、Plan 白名单、流水线短路、Shift+Tab、`/do` 和 `/clear` 符合需求。
- 三态审批、永久规则原子写入/失败、取消恢复和统一 shell 均有测试。
- 混合批次保序回灌、只读并发、跨协议一致及 ch04/ch05 回归通过。
- `.kcode/config.yaml` 与 local 权限文件被忽略，项目权限可跟踪；版本为 0.4.0。
