# KCode Agent Loop Checklist

## 实现完整性

- [x] 普通请求可经历至少三轮工具并自动给出最终文本。（假 Provider 集成测试）
- [x] 文本/思考实时显示，完整响应能还原工具、停止原因、连续状态和 usage。（交错流测试）
- [x] 每轮有模式、轮次、阶段进度，并正确报告本次与累计 Token。（事件断言）
- [x] 六种停止原因唯一，停止后不再请求 Provider。（参数化测试）
- [x] 工具错误、拒绝和参数错误可回灌并继续调整。（失败恢复测试）

## 并发与安全

- [x] 同批只读工具重叠且不超过上限，结果按调用索引排列。（并发计数测试）
- [x] 副作用工具互不重叠并形成前后批次屏障。（时间线测试）
- [x] Plan Mode 仅允许读工具和白名单命令，其他调用不弹确认框。（策略集成测试）
- [x] Do Mode 保留既有确认；拒绝后无副作用。（Textual pilot）
- [x] Ctrl+C 可停止流、授权、并发工具和命令并清理进程。（取消测试）

## 状态与协议

- [x] 异常停止保留完整检查点并丢弃当前残片。（历史测试）
- [x] `/plan`、`/do`、`/clear` 的模式和一次性计划行为正确。（Session/TUI 测试）

- [x] 缺失 usage 显示未知且不污染累计值。（缺失数据测试）
